# fullstack-checkout-challenge

Aplicación de checjout de productos con pago mediante tarjeta de crédito,
integrando con una pasarela de pagos externa (unicamente en sandbox).

##Stack de desarrollo

- **Backend**: NestJS + Typescript + TypeORM
- **Frontend**: React + Typescript + Vite + Redux Toolkit + Tailwind CSS
- **Base de datos**: PostgreSQL
- **Test**: Jest
- **infraestructura**: Docker / Docker Compose
